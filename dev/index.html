SpectralLines

Fast synthesis of spectra from lists of spectral lines.

A spectrum is a sum of Lines, each a unit-area LineShape centred at a position and scaled by an amplitude. calculate_lines evaluates that sum on a grid with one of four methods:

MethodUse when
PointSamplethe grid resolves every line
BinAveragethe grid spacing is comparable to or coarser than the linewidths
LDMthe line list is large (10⁵ lines and more) and the shapes are Voigt, Gaussian or Lorentzian
SparseLDMas LDM, when each width bin's lines cover only part of the grid

An instrument profile is applied per line with convolve where a closed form exists, or to the synthesized spectrum with calculate_lines(xs, lines, instrument_function).

Example

using SpectralLines

lines = [Line(1000.0, 1.0, Voigt(0.05, 0.02)),
         Line(1000.4, 0.5, Voigt(0.03, 0.01))]
xs = range(999.0, 1001.0, length = 2001)

spectrum = calculate_lines(xs, lines, PointSample())   # direct evaluation
spectrum = calculate_lines(xs, lines, LDM())      # fast for 10⁵+ lines

# instrument broadening, analytic per line
broadened = calculate_lines(xs, convolve.(lines, Gaussian(0.02)), PointSample())

SpectralLines.BinAverage — Type
BinAverage(; bin_width, wing_cut=nothing, min_amplitude=nothing)

Bin-averaged line synthesis: each grid point accumulates the profile's mean value over a bin of width bin_width centred on the point, (1/bin_width) ∫ φ(x) dx, rather than a point sample. If wing_cut is set, each line is only evaluated within ±wing_cut × hwhm of its centre; this needs an ascending grid.

Use BinAverage when the grid spacing is comparable to or coarser than the linewidth. There point samples miss most of a narrow line or overweight it, depending on where its centre falls between grid points; with bin_width equal to the grid step, the bins tile the axis and each line keeps its area. Use PointSample when the grid resolves the profile.

Gaussian{T} <: LineShape{T}

Gaussian line-shape profile parameterized by its standard deviation sigma.

\[G(x;\,\sigma) = \frac{1}{\sigma\sqrt{2\pi}}\exp\left(-\frac{x^2}{2\sigma^2}\right)\]

Normalized to unit area. Construct with Gaussian(σ).

SpectralLines.Kielkopf — Type

Kielkopf (1973) combined FWHM f ≈ 0.5346 f_L + √(0.2166 f_L² + f_G²) + Thompson cubic η. Cheaper to construct than Thompson; evaluation costs the same.

source
SpectralLines.LDM — Type
LDM(; res_G=0.01, res_L=0.01, fftw_threads=default_fftw_threads())

Fast approximate line synthesis by the discrete integral transform (DIT) of van den Bekerom & Pannier (2021), RADIS's default method. Its cost is nearly independent of the line count, so it targets large line lists (10⁵+); PointSample/BinAverage are simpler and exact for small ones.

res_G and res_L set the resolution of the Gaussian and Lorentzian width grids: smaller values are more accurate and slower.

Requires an ascending xs::AbstractRange and Voigt/Gaussian/Lorentzian line shapes; lines centred outside xs are dropped. calculate_lines! allocates intermediate buffers; pass a LDMWorkspace to reuse them across calls. Memory grows with the grid length times the number of distinct Gaussian and Lorentzian widths present.

Forward-mode differentiable once ForwardDiff is loaded, at 1 + n_partials times the FFT cost. The derivative is that of the LDM approximation, so it differs from the true derivative at the res_G/res_L level, and the position derivative is piecewise constant per grid cell. PointSample/BinAverage differentiate exactly.

fftw_threads sets the FFTW thread count (default: half the machine's CPU threads, see default_fftw_threads). It is used only for large grids (2¹⁷ points or more after padding) and only when Julia runs single-threaded. With julia -t N the work is parallelized over Julia threads instead. Set fftw_threads = 1 to keep FFTW serial.

LDM also convolves a stick spectrum with one instrument profile: give every line the same shape.

lines = [Line(λ[i], amp[i], Gaussian(σ_inst)) for i in eachindex(λ)]
spec = calculate_lines(grid, lines, LDM())

LDMWorkspace()

SpectralLines.Line — Type
Line{Tx, Ta, LS<:LineShape{Tx}}

A single spectral line: a shape (any LineShape) centred at position and scaled by amplitude. Callable as line(x), evaluating amplitude * shape(x - position).

Construct with Line(position, amplitude, shape). Integer arguments are converted to floating point.

calculate_lines and calculate_lines! sum many Lines over a grid to build a spectrum.

Fields

  • amplitude::Ta: scale factor
  • shape::LS: the (possibly instrument-convolved, see convolve) line-shape function

SpectralLines.PointSample — Type
PointSample(; wing_cut=nothing, min_amplitude=nothing)

Point-sampling line synthesis: each grid point takes the line shape's value directly. If wing_cut is set, each line is only evaluated within ±wing_cut × hwhm of its centre; this needs an ascending grid.

min_amplitude skips lines whose |amplitude| falls below it. The threshold is absolute, in the units of the amplitudes. Weak lines that are never wanted are better filtered out before the Line objects are built.

Multithreaded when Julia runs with threads (julia -t N).

source
SpectralLines.PseudoVoigt — Type
PseudoVoigt{T, M<:PseudoVoigtModel} <: LineShape{T}

Pseudo-Voigt approximation: a linear blend $\eta\,L + (1-\eta)\,G$ of a Lorentzian and a Gaussian sharing a common combined HWHM. The mixing parameter $\eta$ and the combined FWHM are determined by the mixing model M.

Construct with PseudoVoigt(σ, γ) (default: Thompson()) or PseudoVoigt(σ, γ, model) to select a specific mixing model.

Available models: Thompson, Kielkopf, Olivero, LiuLin, Rocco.

Fields

  • sigma::T: Gaussian width $\sigma$
  • gamma::T: Lorentzian HWHM $\gamma$

SpectralLines.SparseLDM — Type
SparseLDM(; res_G=0.01, res_L=0.01, truncation=nothing)

Variant of LDM that transforms only the parts of xs near each group of lines. It takes the same grids and line shapes, and res_G/res_L have the same meaning.

It is faster than LDM when lines of similar width cover only part of xs, as in a real molecular spectrum, where the Doppler width scales with wavenumber. Lines whose widths do not correlate with position favor LDM.

truncation sets the half-width of the kept wings, in units of xs, the same for every line (RADIS's truncation). The default nothing uses the convolution_support of each line's shape.

Forward-mode differentiable once ForwardDiff is loaded, like LDM and with its caveats. Differentiating with respect to a line width needs a fixed truncation: the default one changes in whole grid points with the width, so the spectrum is not a smooth function of it, and such a call throws.

Warning

The wings are zero beyond the truncation, by default ±10×FWHM. A Lorentzian has about 3% of its area out there. If the far wings matter, use LDM or a wider truncation.

SpectralLines.Triangular — Type
Triangular{T} <: LineShape{T}

Triangular line-shape profile: zero at $|x| \geq w$, linearly rising to a peak at $x=0$, with w the full width at half maximum (so the base spans $2w$). Normalized to unit area. Construct with Triangular(w).

\[T(x;\,w) = \begin{cases} \frac{1}{w}\left(1 - \frac{|x|}{w}\right) & |x| < w \\ 0 & |x| \geq w \end{cases}\]

Its convolution with a Gaussian, Lorentzian or Voigt is not one of this package's shapes, so it has no convolve method. Apply it as an instrument with calculate_lines(xs, lines, instrument_function), which FFT-convolves the synthesized spectrum.

The derivative with respect to w jumps at $|x| = w$. A grid point exactly on that edge gets a zero derivative.

Fields

  • fwhm::T: full width at half maximum $w$
source
SpectralLines.Voigt — Type
Voigt{T} <: LineShape{T}

Voigt line-shape profile: the convolution of a Gaussian (standard deviation sigma) and a Lorentzian (HWHM gamma), evaluated via the real part of the Faddeeva function faddeyeva. Its relative error is below 4×10⁻⁵; sigma == 0 and gamma == 0 give the exact Lorentzian and Gaussian.

\[V(x;\,\sigma,\gamma) = \frac{1}{\sigma\sqrt{2\pi}}\, \operatorname{Re}\!\left[w\!\left(\frac{x}{\sigma\sqrt{2}}+i\frac{\gamma}{\sigma\sqrt{2}}\right)\right]\]

Normalized to unit area. Construct with Voigt(σ, γ).

Fields

  • sigma::T: Gaussian width $\sigma$
  • gamma::T: Lorentzian HWHM $\gamma$

In-place form of calculate_lines: overwrite ret with the spectrum synthesized on xs and return it. LDM and SparseLDM additionally accept a LDMWorkspace / SparseLDMWorkspace as fifth argument, which makes repeated calls (near-)allocation-free.

SpectralLines.calculate_lines — Method
calculate_lines(xs, lines, instrument_function[, strategy]; wing_cut=nothing, min_amplitude=nothing) -> Vector

Spectrum of lines on xs, broadened by instrument_function (any callable with an fwhm method). Synthesis uses PointSample with the given keywords.

strategy is SpectrumConvolution (default) or LineConvolution. SpectrumConvolution needs an evenly-spaced, ascending xs that resolves the narrowest line.

SpectralLines.calculate_lines — Method
calculate_lines(xs, lines, method::LineSynthesisMethod) -> Vector

Allocating variant of calculate_lines!.

Automatic differentiation

PointSample and BinAverage are forward-mode differentiable: a ForwardDiff.Dual in a line's position, amplitude or shape parameters propagates through. LDM and SparseLDM are differentiable too once ForwardDiff is loaded (see LDM for the accuracy caveats).

Reverse mode (Zygote, Enzyme) is unsupported for now.

SpectralLines.convolution_support — Method
convolution_support(shape) -> (lo, hi)

The offset range (lo, hi) around the shape's centre (lo ≤ 0 ≤ hi) outside of which shape is zero or negligible. Sizes the kernels and padding of the FFT convolutions.

The fallback, for shapes with unbounded support, is ±10 × fwhm(shape). Shapes with finite support override it, e.g. Triangular.

SpectralLines.convolve — Method
convolve(shape1, shape2) -> LineShape
convolve(line::Line, shape) -> Line

Analytically combine two line shapes into the closed-form LineShape their convolution equals: Gaussian⊛Gaussian → Gaussian, Lorentzian⊛Lorentzian → Lorentzian, Gaussian⊛Lorentzian → Voigt, and Voigt with any of the three. These are exact. A Line is convolved through its shape, keeping position and amplitude. convolve(x, nothing) = x is a no-op, for when no instrumental broadening is requested.

PseudoVoigt and Triangular have no convolve method. For a Triangular instrument, use calculate_lines(xs, lines, instrument_function), which FFT-convolves the synthesized spectrum.

SpectralLines.faddeyeva — Method
faddeyeva(z::Complex) -> Complex
faddeyeva(x, y) -> Real

The Faddeeva (scaled complex complementary error) function

\[w(z) = e^{-z^2} \operatorname{erfc}(-iz), \quad z = x + iy,\]

whose real part gives the Voigt profile: V(x; σ, γ) = faddeyeva(x/(σ√2), γ/(σ√2)) / (σ√(2π)). The two-argument form returns real(w(x + iy)) with real arithmetic, about twice as fast.

Relative error is below 4×10⁻⁵, and the value jumps by up to that error where the approximation switches between regions of the complex plane. The method combines a Laplace continued fraction, Humlíček's w4 formula and Weideman's rational approximation, with regions chosen as in Zaghloul's Algorithm 985.

Float32 and Float64 arguments give results of the same type. Differentiable with ForwardDiff, with derivative errors below 4×10⁻⁵ relative to $|w'|$.

References

  • Zaghloul, M. R. (2017). Algorithm 985: Simple, efficient, and relatively accurate approximation for the evaluation of the Faddeyeva function. ACM Trans. Math. Softw., 44(2), 22. doi:10.1145/3119904
  • Humlíček, J. (1982). Optimized computation of the Voigt and complex probability functions. J. Quant. Spectrosc. Radiat. Transfer, 27(4), 437–444. doi:10.1016/0022-4073(82)90078-4
  • Weideman, J. A. C. (1994). Computation of the complex error function. SIAM J. Numer. Anal., 31(5), 1497–1518. doi:10.1137/0731077

SpectralLines.integrate — Method
integrate(shape, a, b) -> T

The integral $\int_a^b \text{shape}(x)\,dx$, with a and b positions relative to the line centre. BinAverage uses it to average each line over a grid cell, which matters once the grid spacing is comparable to the linewidth.

Exact to rounding for every shape except Voigt, whose relative error is below 0.02%.

SpectralLines.numtype_convert — Method
numtype_convert(::Type{T}, shape) -> LineShape{T}

Rebuild shape with its numeric type parameter changed to T, leaving any non-numeric type parameters intact. Used by Line to promote a shape to the numeric type of the line's position.

The generic fallback calls Shape{T}(shape), which binds T to the first type parameter. Every shape in this package leads with its numeric parameter. A custom shape that does not must define its own method.

SpectralLines.update_lines! — Method
update_lines!(lines; positions=nothing, amplitudes=nothing, shapes=nothing) -> lines

Replace the given per-line fields of lines in place; omitted fields are kept. For fitting loops that re-synthesize with new parameters without rebuilding the line list.

New values are converted to the types already stored in lines. A different type (a ForwardDiff.Dual, another shape family) needs a freshly built line list. Throws DimensionMismatch unless every supplied vector shares indices with lines.

Use it only when all lines have the same shape type. For a mixed-shape vector, rebuilding the list is faster.
